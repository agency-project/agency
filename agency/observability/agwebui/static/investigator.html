Run or connect your agents

Agent execution requires a Linux x86-64 host, Python 3.12+, and a local working Docker or Podman engine. Model credentials and harness setup are required for real agent tasks. The browser can open the profiler URL separately; the Python driver and containers run on the supported host.

from agency import Agent, agdata, agskill
from agency.observability.agwebui import agwebui

TASK = agskill(name="echo", prompt="Return the supplied label.",
               input_schema=agdata(label=str),
               output_schema=agdata(answer=str))

def workload():
    agent = Agent("worker", agconfig=config, harness="native")
    result = agent.run(TASK, agdata(label="hello"))
    result.wait()

# config is your existing validated agconfig (provider + sandbox).
# Call explicitly after configuration. This starts agent/model work.
agwebui.run(workload, run_dir=config.agent.log_dir, port=7860)

Open http://localhost:7860/profiler?run=live. The existing wrapper binds its server to 0.0.0.0; the standalone log viewer can instead bind to loopback using --host 127.0.0.1. A separate viewer pointed at a log directory can inspect events but has no execution relay. No UI action here starts this example.

Use the repository’s examples/10_harnesses_and_webui.py and configuration guide for the verified full setup. Run task is enabled only for skills explicitly registered by that live application; selecting a task does not submit it.
