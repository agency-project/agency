Scope and interpretation:
Terminal-Bench verification runs at native Claude Stop, while task services are alive, before Agency process cleanup. Agency normally terminates traced background processes during cleanup; this measurement does not establish post-return lifecycle parity.
Terminal-Bench checkpoint timings include verifier filesystem changes and are diagnostic. The shared EC2 host also runs other work; latency includes model/tool variability and host contention, so paired runtime differences are not a pure estimate of wrapper overhead.
Session IDs and isolated state-directory paths differ naturally. Initial request matching normalizes only those identities/paths; native Agency request preservation compares actual request contents, Anthropic beta/version headers, and exact attempt counts. Other transport headers are not claimed byte-identical.
These samples provide a supporting measurement, not proof of statistical equivalence. All failures and timeouts remain in the denominator; no final tasks were replaced based on outcomes.
Earlier cohorts were withdrawn in full after discovering missing SYS_PTRACE capability, a scoring setup problem, nested SDK retries during a provider outage, or lost refusal response metadata and fallback model remapping. Original outputs remain on EC2 and are listed in discovery-cohorts.json; they are not pooled with final results.
Fixes: native request/HTTP-error preservation; tab-aware prompt acknowledgment and turn fencing; explicit hook interpreter; robust usage accounting; cgroup-v2 CPU quota detection; SYS_PTRACE for credential-changing children; native response/control fields and per-request fallback model preservation; native CLI retry ownership and safe retry response headers.
Regression checks: native response/request correction 503 passed, 1 skipped; three response/fallback regressions fail on the previous source and pass after correction. Retry correction 177 passed, 1 skipped; the previous source fails all eight native retry cases while the corrected source passes. Capability checks: 171 passed, 7 skipped for the final capability/native-process suite; prior focused native-request suite 204 passed, 11 skipped. The credential-change reproduction fails without the capability and succeeds with it.
Final request auditing matches occurrences of complete JSON-body/header pairs, including beta-header variants used by native recovery. The frozen analyzer and an analysis amendment are retained; no model attempts changed.
Observed Agency Docker checkpoint failures occurred after native Stop when docker commit exceeded its 120-second per-attempt timeout; these remain invocation failures and are separate from native task rewards.
Original and grading patches plus baseline inventories are retained. Project patch scoring excludes files already untracked in the initial image, including generated build files; genuinely new source files and tracked edits remain.
