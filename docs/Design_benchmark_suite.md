# Benchmark Suite Table

Use fake/mock LLM replay as the default harness for all end-to-end benchmarks.
Live model runs can be optional demos, but should not be the primary benchmark
score because model latency, provider load, network variance, and output drift
hide host-side runtime costs.

| Category | Benchmarks to run | Specific metrics to collect | Tools needed |
|---|---|---|---|
| CPU compute | Tree-sitter AST parse and incremental reparse; repo-scale `ripgrep`; `ruff`/`mypy`/`pyright`; `git apply` patch workload. | Wall time; user/system CPU time; thread CPU time; cycles; instructions; context switches; cache references/misses; branch misses. | `perf stat`; `perf record`; `time.thread_time_ns`; `py-spy`; tree-sitter; `ripgrep`; `ruff`; `mypy`/`pyright`; `git`. |
| Memory and cache | Large-context tokenization; long conversation history hydration; context compaction; JSON stream parsing; embedding-index lookup. | Peak RSS; current RSS; cgroup memory peak; allocation count/size; major/minor page faults; cache misses; tokenizer throughput; index lookup latency. | cgroup v2 `memory.current`/`memory.peak`; `psutil`; `tracemalloc`; `perf`; `tiktoken` or HF tokenizers; `ijson`/`orjson`; FAISS or HNSWLib. |
| Storage I/O | Repo-wide file reads; sandbox file read/write/copy; Docker/Podman `run`, `exec`, `commit`, restore; log/trace JSONL writes; vector-index persistence. | Bytes read/written; read/write ops; I/O wait time; Docker run/exec/commit latency; file copy latency; trace write latency; fsync cost; container image size delta. | cgroup v2 `io.stat`; Docker/Podman `events`; Docker/Podman `stats`; eBPF/bpftrace block I/O probes; `hyperfine`; Agency sandbox spans. |
| Concurrency and scheduling | Parallel `agent.run`; fork fan-out; process-pool tool calls; MCP server fan-out; Docker semaphore saturation; context-chain dependency waits. | Throughput; p50/p95/p99 latency; lock wait time; semaphore wait time; process-pool queue wait; run-queue delay; runnable threads/processes; deadlock/timeouts. | `agspan` wait spans; `/proc/<tid>/schedstat`; eBPF scheduler probes; Python `concurrent.futures` timing; OpenTelemetry spans; stress harness. |
| Local GPU / accelerator | Embedding batch; small local LLM via vLLM or llama.cpp; image OCR; speech transcription; GPU-backed sandbox command. | GPU utilization; GPU memory used/peak; power draw; kernel busy time; model throughput; time to first token; tokens/sec; GPU lease wait; CPU overhead while GPU runs. | NVIDIA `pynvml`; `nvidia-smi dmon`; AMD `rocm-smi`; vLLM; llama.cpp; local embedding model; OCR/speech tools; Agency GPU lease spans. |
| Network and API mediation | OpenAI-compatible SSE replay; request batching; retry/backoff; TLS overhead; slow/lossy endpoint; partial or malformed stream. | Time to first token; inter-token latency; total stream time; retries; backoff duration; timeout count; bytes sent/received; TLS handshake time; request queue wait. | Fake OpenAI-compatible SSE server; FastAPI/uvicorn; `httpx` timing hooks; Toxiproxy or `tc netem`; OpenTelemetry HTTP spans. |
| Fake/mock LLM replay | Deterministic tool-call traces; zero-latency replay; fixed-latency replay; realistic streaming replay; retry replay; long-context replay. | Synthetic model wait; LLM call count; expected-vs-actual tool calls; prompt/completion/cache/reasoning tokens; replay divergence; trace step index; deterministic final state. | Custom fake LLM server; JSON trace files; OpenAI-compatible chat/completions API; SSE streaming; token-usage stubber; replay verifier. |
| End-to-end agent loops | Bug-fix loop; refactor loop; test-generation loop; doc-generation loop; benchmarked against mocked model traces. | Total wall time; bucketed wall time: `model_wait`, `cpu_busy`, `io_wait`, `gpu_busy`, `sync_idle`, `residual`; tool count; LLM count; sandbox lifecycle time; peak memory; I/O bytes; success/failure. | `agspan`; `aglog`; fake LLM replay server; pytest benchmark harness; Docker/Podman; cgroup counters; optional OpenTelemetry/Jaeger trace export. |
| Cross-run environment | Every benchmark run. | CPU model; core count; memory; OS/kernel; cgroup mode; Docker/Podman version; GPU model/driver; Python version; Agency git commit; benchmark config; thermal/power mode if available. | `platform`; `/proc/cpuinfo`; `/proc/meminfo`; `docker version`/`podman version`; `nvidia-smi`/`rocm-smi`; `git rev-parse`; `environment.json`. |
