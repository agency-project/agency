Harness-facing API
These are exposed by the sandbox-side Harness Manager daemon:
Method	Endpoint	Purpose
POST	/v1/chat/completions	OpenAI Chat Completions
POST	/v1/responses	OpenAI Responses API
POST	/v1/messages	Anthropic Messages API
POST	/v1/messages/count_tokens	Anthropic token estimate
POST	/agpolicy/check_tool	Tool permission hook
POST	/agprof/hook	Profiler event hook
GET	/agprof/status	Profiler availability
POST	/internal/context_limit	Context-window lookup for native harness
GET	/mcp	MCP Streamable HTTP
POST	/mcp	MCP Streamable HTTP
DELETE	/mcp	MCP session termination


Host → sandbox internal control API
These travel over the private per-agent daemon UDS:
Method	Endpoint	Purpose
POST	/harness_attempt	Run one HarnessAttemptRequest and return HarnessAttemptResult
POST	/control/pause	Pause at the next safe checkpoint
POST	/control/resume	Resume a paused harness
